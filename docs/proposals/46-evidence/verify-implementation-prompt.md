P:37 already forbids exclusion authorization.

**Exact edit** — replace P:15 from “A light run” through “publish-when-verified.” with:

> In strict certified-only mode, adopt a matching full green or return certificate-changed without starting another gate, advancing default or pushing. In publish-when-verified mode, a light, missing or stale certificate permits one full gate within the same attended call and the approved scope. A matching full red stays red in either mode.

**Exact edit** — insert after the first sentence of P:39:

Record the queue mode, order reference, actual exit and remote readback. An unordered certification is an exit-21 hold only while the exact full proof remains valid.
