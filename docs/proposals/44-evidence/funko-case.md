## Why documentation was blocked

1. **Engine G1 is a pre-commit whole-project static gate.** The report handler identifies changed test files, invokes `bash .pandacorp/verify.sh --light` with optional `--tests=`, and rejects on nonzero before staging and committing an ordinary docs report. The actual `8963bb83` project script selects the broad static suite for light and only adds Vitest when tests are explicitly selected. Both red lane reports are partial and list static stages only. Their unit and failure states did not require the Claude Stop hook to intervene. [P/plugin/runtime/build/report.mjs:166–178,286–311; `git -C F show 8963bb83:.pandacorp/verify.sh`:38–42,257–264,873–904; B1 failing product and architect lane reports; J1:9–11,26–28]
2. **The first red was a fresh-lane infrastructure defect.** The failing TypeScript file was outside the first product report's docs-only write set. The retry saw generated types and passed. The old base has no `next typegen` step in its verify script. The updated overlay used in run 2 generates Next types when the binary is present and `.next/types` is absent, and run 2's product lane actually records it. [B1/units/u-product-catalog-line-scope/report.json:6,34,43–45; `git -C F show 8963bb83:.pandacorp/verify.sh | rg -n 'typegen|run_cheap_gate tsc'` yields only the tsc line; F/.pandacorp/verify.sh:987–1004,1161; B2 product lane report:7–12,56–59]
3. **The second red was a genuine match against an overbroad documentation rule.** DR-100 scans for the substring `NEEDS CLARIFICATION` anywhere inside an ACTIVE document, including a negated quotation. The rule matched literal prose and the retry changed the wording. This is a docs-linter false positive for unresolved design ambiguity. [`git -C F show 8963bb83:.pandacorp/verify.sh`:873–892; B1 failed architect lane report:38–48; B1 architect attempt-1 blueprint:1146; `git -C F show 9177c74f:docs/frds/frd-06-franchise-backfill/blueprint.md`:1146]
4. **The final block was a test-first dependency combined with schema failure at launch.** The implementation unit depended on the test-writing unit. Worker dispatch selects the report schema, and the Codex launcher passes it as `--output-schema`. The factory patch adds `"type": "integer"` next to `"const": 1` at `properties.schema` and types other const/enum nodes. Run 2 never reached the tests worker, so this case does not demonstrate successful retry of the patch. [J1:39–57; P/plugin/runtime/build/units/dispatch.mjs:19–24; P/plugin/runtime/build/workers.mjs:137–147; C1:15; C2:15; `git -C P show 3105fd55 -- plugin/runtime/build/schemas/report.schema.json`; J2:1–19]

The discussion shows **5 MEASURED** transcript-linked lock-contention stops with zero selected tests.
