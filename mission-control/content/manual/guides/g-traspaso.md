# Pasar el proyecto a otra persona

Retoma desde los documentos y el CLI en un punto seguro. Nunca tomes una lease viva ajena. Una transferencia autorizada conserva el run e incrementa su época; AGENTS.md contiene las instrucciones compartidas.
