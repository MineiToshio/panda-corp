# Handoff: idea → proyecto

Spec convierte una idea elegida en un proyecto con repo y documentos propios. Después de diseño y arquitectura, implement construye el alcance pendiente mediante el CLI común. AGENTS.md es la fuente de instrucciones y CLAUDE.md su importación de una línea.
