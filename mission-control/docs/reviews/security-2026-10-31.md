# Security hardening review, 2026-10-31

This review supersedes the threat-model assumptions of [2026-07-07](security-2026-07-07.md).
The owner approved unauthenticated home-LAN access on 2026-10-12: the live snapshot listens on
`0.0.0.0:1987`. Loopback-only severity reductions and the old claim that security headers and
connection limits are inapplicable no longer hold. Authentication remains an accepted owner trade-off;
Host validation prevents browser DNS rebinding, not access by an untrusted LAN peer.

## Verification scope

The main scoped Vitest batch passed 454 tests across 28 files; the board/work-order/spec batch passed 106 tests and the flow-series batch passed 11. TypeScript validation passed. The
AC-04-012.5 flake was reproduced by delaying ELK completion beyond the default one-second DOM lookup;
waiting for the existing terminal-layout helper passed with the same delay, then the artificial delay
was removed. The application and global test timeouts were not raised.

## Deferred dependency finding H-3

The isolated Next 16.4.3 / js-yaml 3.15.2 candidate (72c12201) was withdrawn after the allowed
three attempts. The manifest and lockfile retain their previous versions. Installed-version and
41 boundary tests passed on the candidate, as did the live security HTTP/browser probe. However,
`navigation-root.reviewer.spec.ts:49` did not mount `wo-detail` after opening an order from the map;
the following legacy-navigation case timed out during cold loads. Both nav-client-refresh cases
and two later navigation-root cases passed. The remainder was interrupted after this blocking
result, so the full 34-test navigation set is unverified.

The first webpack run stalled while compiling a route. Turbopack failed to start FSEvents in this
sandbox. The third run used the repository's isolated-fixture approach and rendered the workspace,
but did not clear the navigation gate above. No reviewer assertion or baseline was edited. The
exact contribution of the framework versus environment/harness remains unverified; this report
does not claim the upgrade caused the navigation failure. Integration needs an isolated comparison
before reintroducing the dependency candidate. H-3 remains open.

This report is a scoped repair review, not a new full secrets/history scan or an independent audit. No production snapshot was deployed or restarted.

## Remaining threat boundary

An allowed Host is not an authenticated user. A trusted LAN peer can still read exposed dashboard
data and invoke the deliberately bounded owner actions. Internet exposure remains unsupported.
The standalone CLI writers and their state files are separate from app navigation. The only
render-time factory write is the corroborated owned guild ledger; status, authored documents and
project change decisions remain untouched by reads.
