# S3 · Independent audit of the Órbita design freeze

Auditor: fresh read-only reviewer (opus), 2026-10-22. Scope: the gate output, `preflight.json`, `packs/_global.md`, the hand-off files, the FRDs/FDDs and their mocks, `oracle-states.json`/`oracle-recipes.*`/`computed-styles.json`/`fidelity.config.json`, the prototype sources, `open-points.md`, the decision log (2026-10-21) and `m1-decisions.md`. Every finding below was checked against the live file (line numbers are as of this audit).

## Mechanical baseline (verified, no blocker)

- `check-design-gate.mjs`: NOT READY only on the three expected items (`a11y-report.md` being generated, the logo SVGs as an owner question, the tracker's open S3+ rows). Every `check-fdd-coverage` line is OK. Not re-flagged.
- `preflight.json`: complete, newer than the prototype, 0 failures, 1 warning (`literalLengths`) acknowledged in the tracker.
- Captures: all 159 oracle entries × their widths × themes resolve to a file (888 of 888). Every file is a valid JPEG/PNG and newer than `index.html`/`prototype.js`/`prototype.css`. `demo=off` and `host=page` are used everywhere.
- Fonts (Space Grotesk, Inter 400-800, JetBrains Mono), 64 exported icons and `design-tokens.json` (`fonts`, `light`, `dark`) are staged and referenced by `reference/css/00-fonts.css`.
- The prototype is transform-only now. `prototype.css` keeps only `transform` transitions, and `@keyframes pop`, `achin` and `tok-in` animate transforms only. This answers the D-1 question in `open-points.md`; the docs that still describe the old CSS are blocker 16.
