# ADR-0008 — Catalog ingestion as a factory skill

## Context

Preparing a work is careful editorial work.

## Decision

A local skill drafts the bundle from approved sources and a checker flags anything without a chapter.

## Consequences

The choice is reversible at the next version; the blueprint records the migration path.
