# FRD-06 — Chapter explorer

## Overview

Chapter explorer covers chapter explorer. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-06-001 — Chapter list per release

- AC-06-001.1 — WHEN the owner opens the screen, the system SHALL show chapter list per release.
- AC-06-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-06-002 — Chapter page with what changed

- AC-06-002.1 — WHEN the owner opens the screen, the system SHALL show chapter page with what changed.
- AC-06-002.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
