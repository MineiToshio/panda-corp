# ADR-0006 — Connection map with a list fallback

## Context

Graphs are hard to use on phones and with a keyboard.

## Decision

Render an interactive map on wide screens and an equivalent list below 768 px.

## Consequences

The choice is reversible at the next version; the blueprint records the migration path.
