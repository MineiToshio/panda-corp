# FRD-04 — Story encyclopedia

## Overview

Story encyclopedia covers story encyclopedia. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-04-001 — Entry and revision model

- AC-04-001.1 — WHEN the owner opens the screen, the system SHALL show entry and revision model.
- AC-04-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-04-002 — Entry page bounded by progress

- AC-04-002.1 — WHEN the owner opens the screen, the system SHALL show entry page bounded by progress.
- AC-04-002.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-04-003 — Characters, places and factions index

- AC-04-003.1 — WHEN the owner opens the screen, the system SHALL show characters, places and factions index.
- AC-04-003.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
