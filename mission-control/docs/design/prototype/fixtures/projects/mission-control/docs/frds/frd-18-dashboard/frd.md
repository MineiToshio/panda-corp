# FRD-18 — Dashboard

## Overview

Dashboard covers dashboard. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-18-001 — Home dashboard cards

- AC-18-001.1 — WHEN the owner opens the screen, the system SHALL show home dashboard cards.
- AC-18-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
