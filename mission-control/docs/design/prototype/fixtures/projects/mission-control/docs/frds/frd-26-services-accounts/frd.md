# FRD-26 — Services and accounts

## Overview

Services and accounts covers services and accounts. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-26-001 — Services and accounts

- AC-26-001.1 — WHEN the owner opens the screen, the system SHALL show services and accounts.
- AC-26-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
