# ADR-0002 — Restoring a discarded idea is the second allowed write

## Context

Discard already writes the idea's frontmatter.

## Decision

Allow restore as the symmetrical, human-triggered write on the same field.

## Consequences

The choice is reversible at the next version; the blueprint records the migration path.
