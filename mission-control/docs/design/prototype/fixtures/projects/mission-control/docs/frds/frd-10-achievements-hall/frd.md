# FRD-10 — Achievements hall

## Overview

Achievements hall covers achievements hall. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-10-001 — Trophy catalogue

- AC-10-001.1 — WHEN the owner opens the screen, the system SHALL show trophy catalogue.
- AC-10-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-10-002 — Secret achievements

- AC-10-002.1 — WHEN the owner opens the screen, the system SHALL show secret achievements.
- AC-10-002.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-10-003 — Mission chains

- AC-10-003.1 — WHEN the owner opens the screen, the system SHALL show mission chains.
- AC-10-003.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
