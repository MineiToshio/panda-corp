# FRD-07 — Contact

## Overview

Contact covers contact. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-07-001 — Contact form with a hosted form service

- AC-07-001.1 — WHEN the owner opens the screen, the system SHALL show contact form with a hosted form service.
- AC-07-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
