# FRD-08 — Blog writer skill

## Overview

Blog writer skill covers blog writer skill. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-08-001 — Skill entry point and prompts

- AC-08-001.1 — WHEN the owner opens the screen, the system SHALL show skill entry point and prompts.
- AC-08-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-08-002 — Topic intake from notes

- AC-08-002.1 — WHEN the owner opens the screen, the system SHALL show topic intake from notes.
- AC-08-002.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-08-003 — Outline draft

- AC-08-003.1 — WHEN the owner opens the screen, the system SHALL show outline draft.
- AC-08-003.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
