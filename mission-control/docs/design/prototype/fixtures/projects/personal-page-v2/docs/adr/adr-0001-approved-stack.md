# ADR-0001 — Approved stack: static Next.js with MDX

## Context

A portfolio needs speed and easy writing, not a database.

## Decision

Next.js with MDX content in the repository and static generation per language.

## Consequences

The choice is reversible at the next version; the blueprint records the migration path.
