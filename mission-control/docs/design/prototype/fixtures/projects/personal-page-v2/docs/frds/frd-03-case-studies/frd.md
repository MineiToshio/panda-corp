# FRD-03 — Projects and case studies

## Overview

Projects and case studies covers projects and case studies. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-03-001 — Project index from content files

- AC-03-001.1 — WHEN the owner opens the screen, the system SHALL show project index from content files.
- AC-03-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-03-002 — Case study template

- AC-03-002.1 — WHEN the owner opens the screen, the system SHALL show case study template.
- AC-03-002.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-03-003 — Case study image gallery

- AC-03-003.1 — WHEN the owner opens the screen, the system SHALL show case study image gallery.
- AC-03-003.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
