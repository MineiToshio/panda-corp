# FRD-04 — About and now

## Overview

About and now covers about and now. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-04-001 — About and now pages

- AC-04-001.1 — WHEN the owner opens the screen, the system SHALL show about and now pages.
- AC-04-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
