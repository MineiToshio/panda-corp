# FRD-02 — Home and positioning

## Overview

Home and positioning covers home and positioning. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-02-001 — Home hero and proof strip

- AC-02-001.1 — WHEN the owner opens the screen, the system SHALL show home hero and proof strip.
- AC-02-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
