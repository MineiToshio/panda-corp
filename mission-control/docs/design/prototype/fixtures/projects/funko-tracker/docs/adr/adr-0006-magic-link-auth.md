# ADR-0006 — Passwordless sign-in with magic links

## Context

Collectors visit a few times a month and forget passwords.

## Decision

Email magic links with a short expiry and a per-address rate limit.

## Consequences

The choice is reversible at the next version; the blueprint records the migration path.
