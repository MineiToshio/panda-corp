# ADR-0002 — Port the approved prototype CSS in place

## Context

The design phase froze a prototype with measured components.

## Decision

Port its tokens and component styles into the Tailwind registry instead of redrawing the screens.

## Consequences

The choice is reversible at the next version; the blueprint records the migration path.
