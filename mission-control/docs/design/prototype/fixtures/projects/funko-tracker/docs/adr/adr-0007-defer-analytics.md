# ADR-0007 — Defer product analytics until launch

## Context

The v1 is validated with interviews and the share count, which the app already records.

## Decision

Ship without an analytics SDK; the event plan stays written and is wired at release.

## Consequences

The choice is reversible at the next version; the blueprint records the migration path.
