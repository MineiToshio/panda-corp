# FRD-04 — Goals and wishlist

## Overview

Goals and wishlist covers goals and wishlist. It is specified as its own feature so it can be built, reviewed and released independently.

## Requirements

### REQ-04-001 — Goal model per series

- AC-04-001.1 — WHEN the owner opens the screen, the system SHALL show goal model per series.
- AC-04-001.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-04-002 — Missing figures view

- AC-04-002.1 — WHEN the owner opens the screen, the system SHALL show missing figures view.
- AC-04-002.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

### REQ-04-003 — Wishlist toggle and list

- AC-04-003.1 — WHEN the owner opens the screen, the system SHALL show wishlist toggle and list.
- AC-04-003.2 — IF the source is missing, THEN the system SHALL show the designed empty state.

## Out of scope

- Anything that writes to the factory or calls an external service.
