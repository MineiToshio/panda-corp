# /pandacorp:discover

Opportunity discovery **that makes the owner dream AND decide** — in **two phases**, so his taste enters BEFORE the spend. **Phase 1** sweeps wide and cheap: 2-3 hunting lenses, researchers mining only **live-verified sources** (`sources.md`, next to this skill: `plugin/skills/discover/sources.md`), output = **8-12 teasers presented as an inline decision widget** (Claude Code) — each with the problem, the proposed solution, and a first-read of technical viability, so his taste has real substance to pick from. The owner picks the 2-3 that spark. **Phase 2** deep-dives ONLY the picked ones through the hard gates (incl. a real technical-feasibility spike) into **memo-pitch** cards: it sells the value like a pitch to an investor (so a builder says "this is the one") and gives the cold criterio to decide (market, distribution, feasibility, gaps, risk). `$ARGUMENTS` can narrow the niche or pin a lens (e.g.: "/pandacorp:discover extensiones", "/pandacorp:discover tools for teachers"); without arguments, the run picks the lenses.
