# Pandacorp brand mark (owner exception, 2026-10-22)

The brand mark is the existing raster emblem: the panda in the hexagon, an AI-generated illustration with glow and gradients. At M2 of the Órbita freeze the owner decided to keep it as a recorded exception to the vector-logo rule. Mission Control is an internal tool, and the emblem is the guild crest. See `docs/design/freeze/m1-decisions.md` §M2 and `docs/design/design-decisions.md`.

- `pandacorp-mark.png`: the original bytes, identical to `../assets/pandacorp.png` and `public/brand/pandacorp.png`. The build serves this file as is.
- `pandacorp-mark.svg`: the same image, embedded losslessly in an SVG container. It exists for SVG-only consumers. It is not a vector redraw.

A vector redraw is a separate brand task (design skill step 2b) and would need the owner's approval.
