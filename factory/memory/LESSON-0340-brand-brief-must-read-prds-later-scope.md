**Situation:** a first round of brand-mark concepts was briefed from the product's CURRENT scope ("a
reading-companion app"), producing book-bound symbols (pages, a bookmark). The PRD, read in full, already
documented a broader roadmap (manga, series, games, podcasts) that the current-scope brief never
mentioned — the owner rejected the round specifically because the marks would stop making sense once that
roadmap shipped.

**Lesson:** a brand-mark/logo brief scoped only to the product's CURRENT feature set risks producing
concepts bound to a single medium/format that the product's own documented roadmap already plans to
outgrow. The PRD's later scope is not optional context for a branding task — it is a hard constraint on
which symbols and metaphors are even eligible, since changing the mark after launch is expensive and the
roadmap is often already decided by the time branding starts.

**Apply next time:** before briefing any brand-mark/logo generation task, read the PRD's full roadmap
(not just the MVP scope) and state the brand's long-term promise plus an explicit list of forbidden
single-medium/single-format symbols directly in the generation prompt, so concepts are evaluated against
where the product is GOING, not just where it is now.
