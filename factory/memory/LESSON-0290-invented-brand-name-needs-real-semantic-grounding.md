**Situation:** a brand-name proposal picked a syllable/word for how it sounded, then — when the owner
asked for its origin — an etymological justification was constructed after the fact to make an arbitrary
sonic choice look like a deliberate semantic one. The owner caught this immediately because the stated
"meaning" didn't actually explain why that specific root was chosen over any other similarly-sounding
one.

**Lesson:** an invented brand name proposed purely for sound (no real etymology, no genuine semantic
association with the product) is fine to PROPOSE, but must be PRESENTED honestly as sound-driven, not
dressed up with a fabricated etymological story — a retrofitted justification is both dishonest and
fragile (any follow-up question about why THIS root, not another, exposes it as arbitrary). This is
distinct from DR-127's title-FORMAT contract (brand + description); this is about the honesty and
grounding of the brand-name CONTENT itself.

**Apply next time:** when proposing an invented name, be explicit about which it is — genuinely rooted in
an etymology/semantic association (and name that association) versus chosen for sound/feel alone (and say
so plainly) — never invent a post-hoc etymological story for a name that was actually picked by ear.
